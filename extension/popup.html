Toggle Ctrl + W: Settings

Config

If enabled, tabs can be closed with the shortcut.

By enabling it, you can delete the current tab with Ctrl + W.

By disabling it, Ctrl + W will do nothing. You can avoid unintentional tab deletion with Ctrl + W when using Web Terminal (e.g. bash).

Help

If you have not already set up shortcuts, please do so at: chrome://extensions/shortcuts

Recommended settings:

  • Close a tab (Optional): Alt + Shift + W
  • Close a tab if enabled: Ctrl + W
